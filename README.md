## 📝 ポートフォリオ概要

フロントエンドエンジニアを目指して制作した作品をまとめたポートフォリオサイトです。

- 🎓 **デジタルハリウッドSTUDIO 修了**
- 💼 **Astraza Studio** にて Web サイト更新・WordPress 構築などの **実務経験あり**
- 🧩 Web 制作（HTML / CSS / WordPress）に加え、**React・TypeScript・Supabase を用いた Web アプリ開発**まで対応
- 🌐 **GitHub Pages** で公開

> **本ポートフォリオで伝えたいこと**
> 「Web 制作」だけでなく、**データを扱う Web アプリケーション開発**まで一貫して取り組めること。
> そして、**実案件での納品経験**と、**継続的に技術を広げていく成長意欲**があること。

## 👤 自己紹介

はじめまして。フロントエンドエンジニアを目指して、学習と制作に取り組んでいます。

デジタルハリウッドSTUDIO を修了後、現在は **Astraza Studio** にて WordPress サイトの更新・改修や HTML/CSS コーディングなど、**納品を前提とした Web 制作の実務**に携わっています。

実務で培った Web 制作スキルを土台に、**React・TypeScript** を中心としたモダンなフロントエンド開発、さらに **Supabase** を用いた Web アプリ開発へと領域を広げてきました。

「作って終わり」ではなく、**ユーザーにとって使いやすく、運用しやすいプロダクト**を意識して、日々スキルアップに励んでいます。

### ⭐ Study Tracker — 学習管理アプリ

![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white)
![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white)

学習時間や学習内容を記録・管理できる学習管理アプリです。**React + TypeScript** でフロントエンドを構築し、**Supabase によるデータ永続化（CRUD）**、**Vercel での継続的デプロイ**まで実装しました。
Web 制作にとどまらず、**データを扱う Web アプリ開発**まで一貫して対応できることを示す代表作です。

🔗 **[Live Demo](https://study-tracker-delta-rouge.vercel.app/)** ・ 📄 **[Project Proposal](https://hirotonozaki.github.io/study-tracker-proposal/)** ・ 💻 **[GitHub](https://github.com/hirotonozaki/study-tracker)**
